# libnudget

Small developer tools: open source utilities, GitHub Actions, libraries,
and templates for everyday development.

Every project solves one problem well. See the [libnudget website](https://libnudget.github.io)
for the project list, philosophy, and standards.

This repository holds the organization profile and default community
health files for the [libnudget](https://github.com/libnudget)
organization.
