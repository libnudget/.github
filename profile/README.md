# libnudget

Small developer tools.

We make small, open source tools — utilities, GitHub Actions, libraries,
and templates for everyday development. Each one is meant to solve a
single problem, stay small enough to read and reason about, and work
quietly whether you use it alone or together with the others.

The tools don't need to shout. They earn their place by being honest,
useful, and easy to follow. That is the whole idea, and it is the whole
point.

You can find the collection on the website —
[libnudget.github.io](https://libnudget.github.io).

## The projects

Eight tools, each with a small job of its own:

- **clipb** — a lightweight clipboard utility.
- **release-notes** — turns merged pull requests into clean release notes.
- **fmtcheck** — check formatting in CI without the arguments.
- **mini** — a tiny, dependency-free HTTP client.
- **startkit** — a minimal starting point for a new library.
- **craft** — an experimental Rust tool, still finding its way.
- **dotenv-keep** — keeps your `.env` files honest.
- **gh-tag** — tags releases from CI, consistently.

## How we build

We would rather build one thing really well than many things halfway. The
work should speak plainly, match what it says on the tin, and be easy to
replace. Whether a project is a first sketch or here to stay, we try to
give it the same care.

If one of the projects helps you, or breaks for you, we'd like to hear
about it. Fair and willing to be corrected is how this stays useful.
